# Yomi — نُسخ الإصدار (بدون كود)

هذا المستودع **ليس** مستودع الشيفرة. الشيفرة المصدرية خاصة، وهذا المستودع
يحمل فقط: ملف APK الموقّع، وبصمته، وحالة ما يعمل وما لا يعمل.

- **المستودع:** <https://github.com/PanditJi-9/yomi>
- **التنزيل:** تبويب [Releases](../../releases)
- **الحالة:** إصدار تجريبي (pre-release) — اقرأ `STATUS.md` قبل التثبيت.

## التثبيت

1. نزّل ملف `.apk` من صفحة الإصدار.
2. فعّل «تثبيت التطبيقات من مصادر غير معروفة» لمدير الملفات أو المتصفح الذي
   تفتح منه الملف.
3. ثبّت. إن كانت نسخة أقدم مثبّتة، ثبّت فوقها مباشرة — لا حاجة لحذفها،
   والتحديث لا يمسّ المكتبة أو سجل القراءة.
4. المتطلبات: Android 10 (API 29) أو أحدث.

## التحقق من الملف

```bash
sha256sum yomi-0.7.0-6df7318.apk
# يجب أن يطابق السطر في SHA256SUMS
```

بصمة شهادة التوقيع (SHA-256):

```
4B:E8:D1:47:37:11:01:BE:AE:7C:25:02:B1:D5:1A:46:30:CC:83:53:39:F5:30:F6:F6:AB:43:23:24:FA:B3:09
```

لم تُعلن هنا أي بصمة لم يُتحقق منها في CI بـ`apksigner`.

## الصدق أولًا

- الملف هنا يُبنى على GitHub Actions من المستودع الخاص، ويُتحقق من توقيعه قبل
  رفعه.
- **لم يُجرَّب هذا الإصدار على جهاز ضمن بيئة البناء.** ما لم يثبت خلاف ذلك،
  تعامل معه كإصدار تجريبي.
- لا يُرفع هنا ملف debug ولا APK غير موقّع.
- لا تُرفع هنا ملفات مصدرية أو مفاتيح توقيع أو `mapping.txt`.
